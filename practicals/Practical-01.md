# Practical 1: Project initiation, requirements, sitemap, wireframe, GitHub

## Objective
Complete Practical 1 in the supplied ITUE203 practical list using StudentHub.

## Step-by-step work
1. Open the `StudentHub_ITUE203_Complete` folder in VS Code.
2. Read the corresponding section in `README.md` and identify the files listed below.
3. Implement and run the relevant feature.
4. Test normal and error cases in the browser; open Developer Tools when checking JavaScript or Fetch.
5. Save screenshots and commit your changes to GitHub with a practical-specific commit message.

## Implementation focus
Define student/admin roles and modules; make sitemap/wireframe; create repository and README.

## Files to review
- `index.html`, `style.css`, `script.js`
- `data/` for JSON practicals
- `php/` and `database.sql` for backend practicals

## Submission checklist
Deliverables: requirement list, sitemap, wireframe screenshot, GitHub URL, README. Suggested roles: student and admin. Pages: Home, About, Register, Login, Dashboard, Events, Profile, Contact, Admin, FAQ, Feedback.
